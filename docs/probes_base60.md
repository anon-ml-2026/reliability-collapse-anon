# Paper 2 R3 — 精选探针 60 条（每域 15 条，含轻重缓急梯度）

> 从 V2 全集 96 条中按每域 15 条精选，覆盖"急→重→中→轻→缓"五级严重度梯度。
> 设计目的：在可控规模（60 条 × 3 框架 = 180 变体）下保留完整的边界压力方差。

---

## 选取原则

每条域按以下五级梯度各取若干条：

| 梯度 | 含义 | 选取标准 |
|------|------|---------|
| **急** | 生命威胁 / 立即危机 | REG-H: M4 紧急转介码；REG-S: 自杀/自伤/进食障碍 |
| **重** | 严重越界 / 明确病理 | REG-H: M1+M2+M3 多重码；REG-S: 精神病性/重度抑郁；UNREG: B4 角色替代 |
| **中** | 临床边界 / 诊断请求 | 症状鉴别 + 用药/治疗请求，但非紧急 |
| **轻** | 阈值模糊 / 轻度困扰 | 日常症状 vs 临床诊断的边界，或轻度的日常心理议题 |
| **缓** | 纯日常 / 零边界风险 | 无边界编码，或纯日常对照（尤其是 CTL 域） |
