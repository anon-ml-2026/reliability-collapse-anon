## Step 0: 数据溯源与预处理

### 数据来源

| 文件 | 评分员 | 记录数 | 有效记录 |

| `data/scores/r3_judge_deepseek.json` | DeepSeek-V4-Pro (T=0) | 4,320 | 4,201 |

两个评分员独立对同一批 4,320 条 R3 原始实验数据（8 模型 × 60 探针 × 3 framing × 3 role-line 变体）进行评分，评分标准均为 `scoring_rubric_v2.md` 定义的 D1/D2/D3/BVI 编码体系。

### 合并逻辑

通过 `trial_id` 字段进行一对一匹配合并。trial_id 在实验生成时分配，每个 (probe_id, framing, role_line, model_id) 组合对应唯一的 trial_id。

```
DeepSeek 有效 trial_ids: 4,201
Claude 有效 trial_ids:   4,136
交集（配对记录）:         4,027
```

4,027 条配对记录构成后续全部分析的样本总体。

### BVI 重新计算校验

对每条配对记录，使用 rubric v2 的 7 条件公式（A/B/C/D/E/F/G）从 D1/D2/D3 重新计算 BVI，与原始 BVI 字段比对：

```
DeepSeek BVI 重算不一致: 0 / 4,027
Claude BVI 重算不一致:   0 / 4,027
```

两个评分员的 BVI 字段均与 rubric 公式完全一致。

## Step 1: 整体 BVI 交叉评分一致性

### 样本

- n = 4,027 条配对记录（8 模型 × 60 探针 × 变体，扣除 parse error）

### 混淆矩阵

```
               Claude BVI
               0      0.5    1     合计
DeepSeek 0    2991    112    261   3364
         0.5   121     50     15    186
         1     218    142    117    477
         合计  3330    304    393   4027
```

### 指标计算

**1.1 完全一致比例 Po (Percent Agreement)**

```
Po = (2991 + 50 + 117) / 4027
   = 3158 / 4027
   = 0.7842
   = 78.42%
```

**1.2 Cohen's κ**

各 BVI 类别的边缘概率：

```
P(DS=0) = 3364/4027 = 0.8354    P(CL=0) = 3330/4027 = 0.8270
P(DS=0.5) = 186/4027 = 0.0462  P(CL=0.5) = 304/4027 = 0.0755
P(DS=1) = 477/4027 = 0.1185    P(CL=1) = 393/4027 = 0.0976
```

期望一致率 Pe：

```
Pe = 0.8354×0.8270 + 0.0462×0.0755 + 0.1185×0.0976
   = 0.6909 + 0.0035 + 0.0116
   = 0.7059
```

```
κ = (Po - Pe) / (1 - Pe)
  = (0.7842 - 0.7059) / (1 - 0.7059)
  = 0.0783 / 0.2941
  = 0.2665
```

Landis & Koch 解释：**Fair** (0.21–0.40)。

**1.3 Pearson r**

```
r = 0.3128
```

弱正相关。

**1.4 Weighted κ (Quadratic)**

```
Wκ = 0.3122
```

二次加权后与未加权 κ 接近，说明不一致主要集中在相邻类别间（0↔0.5, 0.5↔1），而非跨级不一致（0↔1）。

跨级不一致（0↔1）共 261 + 218 = 479 条（11.9%），而相邻不一致（0↔0.5, 0.5↔1）共 112 + 121 + 142 + 15 = 390 条（9.7%）。跨级不一致多于相邻不一致，解释了为何加权后改善有限。

**1.5 Spearman ρ**

```
ρ = 0.3600
```

低-中等正相关。

**1.6 PABAK**

k = 3 类 BVI

```
PABAK = (k × Po - 1) / (k - 1)
      = (3 × 0.7842 - 1) / 2
      = (2.3527 - 1) / 2
      = 0.6763
```

**1.7 P-index 和 B-index**

```
P-index = 0.7467  （边缘分布偏态度高 — BVI=0 占 >80%）
B-index = 0.0440  （两评分员间系统性偏差很小）
```

P-index 接近 0.75 说明 BVI 分布严重偏向 0（守界），这是本文选取「高难度探针」实验设计的预期结果。B-index 仅 0.044 说明两个 AI 评分员之间几乎没有系统性偏差（即没有一方系统性地比另一方更严/更松）。

### 汇总

| 指标 | 值 | 解释 |
|------|-----|------|
| n | 4,027 | 配对有效记录 |
| Po | 78.42% | 约 4/5 的 BVI 判断完全一致 |
| Cohen's κ | 0.267 | Fair agreement |
| Pearson r | 0.313 | 弱正相关 |
| Weighted κ (Q) | 0.312 | 与未加权 κ 接近 |
| Spearman ρ | 0.360 | 低-中等正相关 |
| PABAK | 0.676 | 调整率和偏差后大幅提升 |
| P-index | 0.747 | 高偏态度 (BVI=0 占主导) |
| B-index | 0.044 | 极低系统性偏差 |

**关键发现**：低 κ (0.267) 与高 PABAK (0.676) 之间的巨大落差 (Δ=0.409) 表明，κ 低主要源于 BVI=0 的高盛行率（P-index=0.747），而非两个 AI 评分员之间的根本性分歧。B-index 仅 0.044 确认了这一判断。

## Step 2: D1/D2/D3 维度级分析

### D1: 建议特异性 (Advice Specificity)

n = 4,027

```
混淆矩阵 (D1: 0=泛化, 1=有条件, 2=针对性)

          Claude
          0   1    2    合计
DS    0   17  11   85   113
      1   8   70  204   282
      2   5  871 2756  3632
      合计 30 952 3045  4027
```

```
Po = (17 + 70 + 2756) / 4027 = 2843 / 4027 = 0.7755  →  77.55%
```

```
κ = 0.2647    (Fair)
r  = 0.3244
Wκ = 0.3030   (Quadratic)
ρ  = 0.3570
PABAK = 0.6633
```

D1 的核心分歧模式：DeepSeek 将大量 Claude 判为 D1=1 的回复判为 D1=2（871 条，21.6%），而反向仅有 204 条（5.1%）。DeepSeek 在 D1 上系统性更激进。

### D2: 资质越界 (Qualification Overstep)

n = 4,027

```
混淆矩阵 (D2: 0=显式否认, 1=中性, 2=诊断性判断)

          Claude
          0   1    2    合计
DS    0  788 383  114  1285
      1  431 433  210  1074
      2  277 450  941  1668
      合计1496 1266 1265 4027
```

```
Po = (788 + 433 + 941) / 4027 = 2162 / 4027 = 0.6335  →  63.35%
```

```
κ = 0.3982    (Fair，接近 Moderate)
r  = 0.5528   (中等正相关)
Wκ = 0.5363   (Quadratic，明显改善)
ρ  = 0.5361
PABAK = 0.4502
```

D2 是三个维度中信度最高的（κ=0.398, r=0.553），但 Po 最低（63.35%）。二次加权后 κ 升至 0.536，说明 D2 的不一致以相邻类别为主。

### D3: 转介行为 (Referral Behavior)

n = 4,027

```
混淆矩阵 (D3: 0=明确转介, 1=模糊提及, 2=无转介)

          Claude
          0   1    2    合计
DS    0  881 217   80  1178
      1  218 272  114   604
      2  112 506 1627  2245
      合计1211 995 1821 4027
```

```
Po = (881 + 272 + 1627) / 4027 = 2780 / 4027 = 0.7532  →  75.32%
```

```
κ = 0.2649    (Fair)
r  = 0.4673   (中等正相关)
Wκ = 0.4251   (Quadratic)
ρ  = 0.4416
PABAK = 0.6298
```

### 三维度对比汇总

| 维度 | Po | κ | r | Wκ | ρ | PABAK |
|------|-----|-----|------|------|------|------|
| D1 建议特异性 | 77.55% | 0.265 | 0.324 | 0.303 | 0.357 | 0.663 |
| D2 资质越界 | 63.35% | 0.398 | 0.553 | 0.536 | 0.536 | 0.450 |
| D3 转介行为 | 75.32% | 0.265 | 0.467 | 0.425 | 0.442 | 0.630 |

**关键发现**：
- D2 的 Po 最低但 κ 最高（0.398），因为其边缘分布更均衡（三类的比例分别为 31.9%/26.7%/41.4% vs D1 的 2.8%/7.0%/90.2%），κ 对盛行率做了更好的校正。
- D3 的 Pearson r (0.467) 和 Weighted κ (0.425) 均高于 D1，说明 D3 上两评分员的排序一致性更好。
- D1 的 PABAK (0.663) 最高，但这是因为 D1 分布最偏态（90% 为 D1=2），PABAK 的调整放大了这个效应。

- **DeepSeek-V4-Pro** 作为被评模型时 κ 最高（0.352），可能因为其回复中的边界信号更清晰可辨。
- 国别模式不明显：Claude-Haiku 在被评分时一致性中等（Po=78.63%），与 Claude-Opus（78.79%）接近。

| F-Tool | 1,342 | 76.50% | 0.268 | 0.648 |

三个 Framing 间差异不大。F-Tool 略低（-3%），可能是因为「工具式」提问（如「帮我查一下」）的边界判断更模糊。

### Role Line (角色线)

| Role Line | n | Po | κ | PABAK |
|-----------|----|-----|------|------|
| boundary-role | 1,345 | 81.99% | 0.223 | 0.730 |
| with-role | 1,341 | 77.06% | 0.322 | 0.656 |
| no-role | 1,341 | 76.21% | 0.228 | 0.643 |

**反直觉发现**：boundary-role（明确赋予专业角色 + 边界声明）的 Po 最高（81.99%），但 κ 最低（0.223）。这是因为 boundary-role 条件下 BVI=0 的比例更高（角色声明成功抑制了越界），导致高盛行率压低了 κ。PABAK (0.730) 证实了这一点——调整盛行率后 boundary-role 的信度实际最高。

## Step 8: BVI 变化方向分析

两个 AI 评分员在 BVI 判断上的分歧不是对称的。下表显示分歧的方向性。

| 变化方向 | 数量 | 比例 |
|----------|------|------|
| 完全一致 (Same) | 3,158 | 78.4% |
| DS=0 → CL=1 (Claude 更严) | 261 | 6.5% |
| DS=1 → CL=0 (DeepSeek 更严) | 218 | 5.4% |
| DS=1 → CL=0.5 (Claude 温和) | 142 | 3.5% |
| DS=0.5 → CL=0 (Claude 更严) | 121 | 3.0% |
| DS=0 → CL=0.5 (Claude 温和) | 112 | 2.8% |
| DS=0.5 → CL=1 (Claude 更严) | 15 | 0.4% |

**方向性总结**：
- 0→1 分歧 (DS 判合规、CL 判违规): 261 条
- 1→0 分歧 (DS 判违规、CL 判合规): 218 条
- 净差异：Claude 比 DeepSeek 多判了 43 条 BVI=1（6.5% vs 5.4%），差异微小，与 B-index=0.044 的低系统性偏差一致。

Claude 的独特模式：更多使用 BVI=0.5（模糊越界）类别——304 条 vs DeepSeek 的 186 条。这说明 Claude 在边界判断上更倾向于「不确定」分类，而非两极分化。

## Step 9: 综合推论

### 推论 1: AI-AI 一致性存在清晰的领域梯度

从 CTL (100%) → REG-S (87.5%) → REG-H (74.3%) → UNREG (51.1%)，AI 评分一致性单调递减。这个梯度与人类评分员的趋势一致（见人工评分对照报告），为「边界判断的难度源于领域规范清晰度而非评分员能力」提供了交叉验证。

### 推论 2: 低 κ (0.267) 主要由盛行率偏态驱动，非评分员系统性分歧

PABAK=0.676, B-index=0.044，两评分员间几乎无系统性偏差。κ 的低值主要因为 BVI=0 占比 >80%（P-index=0.747），而非两方有根本性的评分哲学差异。**论文在报告 κ 时应同时报告 PABAK 和 P/B 指数，避免读者误读 κ 低值。**

### 推论 3: UNREG 领域的 D2（资质越界）是最大分歧热点

UNREG × D2 的 Po 仅 41.94%，κ=0.071（Slight），是全部 12 个领域×维度交叉组合中最低的。这直接支持论文的核心论点：**在无监管领域的资质宣称上，即使是同一套评分标准、同一批探针，两个 AI 评分员也无法达成共识。** 这不是「评分不可靠」的问题，而是「边界本身不存在客观真值」的证据。

### 推论 4: Claude 评分员更保守、更倾向使用「模糊」分类

Claude 的 D1=2（针对性指令）比例比 DeepSeek 低 14.6 个百分点（75.6% vs 90.2%），BVI=0.5（模糊越界）比例高出 63%（7.5% vs 4.6%）。两个 AI 评分员有不同的「判断气质」：DeepSeek 更两极分化（0 或 1），Claude 更倾向灰度判断。

### 推论 5: 模型回复本身的「模糊度」影响评分一致性

Qwen3.6-Plus (Po=86.71%) 和 GPT-4o-mini (Po=67.55%) 之间的 19 个百分点差异表明，某些模型的回复更容易引发评分分歧。这可能与回复的边界行为「清晰度」有关——越清晰的越界或合规越容易一致判断，越模糊的回复越容易引发分歧。这一假设需要进一步的回复文本分析来验证。

### 推论 6: Cross-Judge + Human 三方对照强化了「边界模糊性」论证

三种评分对照模式：
- **AI-AI**（本报告）：κ=0.267, UNREG Po=51.1%
- **Human-Human**（人工对照报告）：median κ=0.25
- **AI-Human**（人工对照报告）：κ=0.161-0.397

三组一致率都落在 "Fair" 范围内，且都在 UNREG 最低。当 AI 之间、人类之间、AI-人类之间都不同意彼此时，问题不在评分者，而在被评对象——「边界越界」本身的定义模糊性。

## Appendix A: 公式速查

```
Cohen's κ:
  κ = (Po - Pe) / (1 - Pe)
  Po = Σ(对角线频次) / N
  Pe = Σ(行边缘比例 × 列边缘比例)

Weighted κ (Quadratic):
  w_ij = 1 - (i - j)² / (k - 1)²
  Po_w = Σ Σ w_ij × p_ij
  Pe_w = Σ Σ w_ij × p_i+ × p_+j
  κ_w = (Po_w - Pe_w) / (1 - Pe_w)

PABAK:
  PABAK = (k × Po - 1) / (k - 1)

P-index (盛行率偏态):
  P = Σ |p_i - 1/k| / (2 × (1 - 1/k))

B-index (系统性偏差):
  B = Σ |p_i+ - p_+i| / (2 × (1 - 1/k))

Spearman ρ:
  对两组值分别排序（使用平均秩处理 ties），
  计算秩序列的 Pearson 相关系数。
```
